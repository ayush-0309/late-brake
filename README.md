# Late Brake

Top-down F1-style racing on real Grand Prix circuits, in the browser. Plain HTML, Canvas and JavaScript modules, no build step.

## Run locally

```bash
npm run dev
```

Then open http://localhost:5173/play.html. Any static file server works; the page just has to be served over HTTP (not opened as a file) because it uses ES modules.

## Layout

| File | What it does |
| --- | --- |
| `play.html`, `style.css` | Game page: menu, HUD, touch pedals |
| `src/circuits.js` | Real circuit outlines in meters (generated, don't edit) |
| `src/track.js` | Circuit settings (width, runoff, blurb), spline centerline, barriers, nearest-point projection |
| `src/car.js` | Fixed-timestep F1-style physics (downforce grip, aero drag) and barrier collisions |
| `src/session.js` | One time-trial run: laps, sectors, track limits, ghost recording, live delta (no DOM) |
| `src/render.js` | Canvas drawing: track, cars, ghost, skid marks, minimap |
| `src/scenery.js` | Trackside world, generated per circuit: runoff, tyre walls, ad boards, grandstands, pit lane and garages, grid slots, trees or city blocks |
| `src/ads.js` | Ad inventory for every board, painted runoff logo and roof |
| `src/audio.js` | Sound (Web Audio): real F1 engine loops pitched by rpm and gear; synthesized brakes, tyres, kerbs, grass, impacts, race cues |
| `sounds/` | Engine loops, generated by `tools/make-engine-loops.mjs` from `data/sounds/` |
| `src/input.js` | Keyboard + on-screen pedals |
| `src/storage.js` | Best laps and ghosts in localStorage |
| `src/main.js` | Game loop, menus, HUD |

Handling constants live in `CAR` at the top of `src/car.js`.

## Ads

Every ad slot in the game (boards along the barriers, logos painted on tarmac runoff, grandstand and pit roofs) takes its creative from `src/ads.js`. Edit `ADS` for the default set, or add an entry to `TRACK_ADS` to give one circuit its own sponsors. A creative is text (`{ text, bg, fg }`) or an image (`{ image: 'ads/brand.png', bg }`).

## Circuits

Red Bull Ring, Monza, Silverstone, Spa-Francorchamps, Monaco and Interlagos, at real scale and in race direction.

To add another, put its id in `IDS` in `tools/import-circuits.mjs`, run `node tools/import-circuits.mjs`, then add its settings to `SETTINGS` in `src/track.js`. Ids are listed in `data/f1-circuits.geojson` (40 circuits). Circuits that cross themselves, like Suzuka, need bridge support first.

## Controls

Arrows or WASD to drive, R restart, G toggle ghost, M sound on/off, Esc pause. On touch screens, pedals and steering buttons appear.
