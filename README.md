# Late Brake

Top-down formula racing on real-world circuits, in the browser. Plain HTML, Canvas and JavaScript modules, no build step.

## Run locally

```bash
npm run dev
```

Then open http://localhost:5173 (landing page) or http://localhost:5173/play.html (the game). Any static file server works; the page just has to be served over HTTP (not opened as a file) because it uses ES modules.

Live at https://www.latebrake.in. Vercel serves the repo root as-is: there's no build step, and `404.html` handles missing pages. The blog is the one generated part: see "Blog" below.

## Layout

| File | What it does |
| --- | --- |
| `index.html`, `src/landing.js` | Landing page: hero animation, circuit cards, how to play |
| `play.html`, `style.css` | Game page: menu, settings, HUD, touch pedals. `play.html?track=<id>` opens on a circuit |
| `src/settings.js` | Camera, steering sensitivity and ghost settings, saved in localStorage |
| `src/circuits.js` | Real circuit outlines in meters (generated, don't edit) |
| `src/track.js` | Circuit settings (width, runoff, blurb), spline centerline, barriers, nearest-point projection |
| `src/car.js` | Fixed-timestep formula-car physics (downforce grip, aero drag) and barrier collisions |
| `src/session.js` | One time-trial run: laps, sectors, track limits, ghost recording, live delta, reset to track, lap rescue (no DOM) |
| `src/race.js`, `src/ai.js` | Races against AI: grid, AI drivers on the racing line, car-to-car contact, positions, results (no DOM) |
| `src/online.js`, `src/online-ui.js`, `src/online-mock.js` | Accounts, leaderboards, daily challenge and shared ghosts (Supabase), their menu and dialogs, and a pretend backend for local testing |
| `src/net.js`, `src/online-race.js`, `src/lobby-ui.js` | Online races for up to 4: rooms (Supabase Realtime, or tabs of one browser for testing), syncing cars, the lobby |
| `src/platform.js` | Web game portals (CrazyGames, Poki): ad breaks between runs and rewarded ads |
| `src/analytics.js` | Privacy-friendly analytics and error reports (Plausible or GoatCounter), off until configured |
| `src/config.js` | Switches for production: sponsor email, analytics, ad portal, Supabase |
| `sponsors.html`, `media/` | Page for advertisers, with screenshots of the ad slots |
| `itch/` | The itch.io listing: its text (`listing.md`), cover, screenshots and the launcher that opens the game here (not deployed) |
| `supabase/` | Database setup for the online features: see `supabase/README.md` |
| `src/line.js` | Racing line (minimum curvature within the track) and speed profile per circuit: throttle / lift / brake zones and braking board positions (no DOM) |
| `src/render.js` | Canvas drawing: chase or top-down camera, track, cars, ghost, skid marks, minimap, menu previews |
| `src/view3d.js` | Cockpit (first-person) view in WebGL: builds a 3D circuit from the same track and scenery data and draws it from the driver's eye. No library |
| `src/car3d.js`, `src/mesh3d.js` | The 3D car (lofted bodywork, tyres, wings, halo, steering wheel) and the shape helpers it's built from |
| `src/scenery.js` | Trackside world, generated per circuit: runoff, tyre walls, ad boards, grandstands, pit lane and garages, grid slots, trees or city blocks |
| `src/ads.js` | Ad inventory for every board, painted runoff logo and roof |
| `src/audio.js` | Sound (Web Audio): real V8 race-engine loops pitched by rpm and gear; synthesized brakes, tyres, kerbs, grass, impacts, race cues |
| `sounds/` | Engine loops, generated by `tools/make-engine-loops.mjs` from `data/sounds/` |
| `src/input.js` | Keyboard, gamepad and on-screen pedals |
| `src/storage.js` | Best laps and ghosts in localStorage |
| `src/medals.js` | Bronze, silver and gold medals per circuit and the car colours they unlock (or that can be bought), in localStorage |
| `terms.html`, `privacy.html`, `refunds.html`, `contact.html`, `pages.css` | Terms of use, privacy policy, refund policy and contact page (payment providers check for these); keep them in step with what the game collects and sells |
| `src/shop.js` | Buying car colours: Dodo Payments checkout over the game, with payments checked by `supabase/functions/shop` |
| `src/main.js` | Game loop, menus, HUD |

Handling constants live in `CAR` at the top of `src/car.js`. The steering sensitivity setting multiplies the steering rate and lock (`SENSITIVITY` in `src/settings.js`).

Icons (`icon.svg`, `icon-*.png`), `manifest.webmanifest` and the share image `og.png` live at the root. To redraw the share image, edit `tools/og.html` and run `tools/make-og.sh` with the dev server running.

## Making money

- **Game portals.** On CrazyGames or Poki (detected automatically) the game shows an ad break between runs (never before the first), and a rewarded ad keeps a lap that went over the track limits (once per lap; the lap then counts as a personal best only and is never uploaded). Nothing shows on our own site. Try the flow locally with `?platform=test`. Check each portal's current SDK docs when submitting: the calls are in `src/platform.js`.
- **Sponsors.** `sponsors.html` describes the ad slots and links to the email in `src/config.js`; the landing page and the menu link to it.
- **Car colours.** Locked colours in the Garage can be bought with Dodo Payments (₹99 to ₹499: shown from `COLOURS` in `src/medals.js`, charged from each colour's Dodo product). Off until `shop: true` in `src/config.js`; setup is in `supabase/README.md`. Buying needs a Google account so the colour follows the player.
- **Supporter pack.** Shown as "coming soon" in the menu; not built yet.

## Ads

Every ad slot in the game (boards along the barriers, logos painted on tarmac runoff, grandstand and pit roofs) takes its creative from `src/ads.js`. Edit `ADS` for the default set, or add an entry to `TRACK_ADS` to give one circuit its own sponsors. A creative is text (`{ text, bg, fg }`) or an image (`{ image: 'ads/brand.png', bg }`).

## Online

Accounts, leaderboards, the daily challenge, shared ghost links and online races need a Supabase project. Setup takes about ten minutes: see `supabase/README.md`. Without it those features stay hidden. `?online=mock` turns on a pretend backend for trying them locally.

## Circuits

Spielberg, Monza, Silverstone, Spa-Francorchamps, Monaco and Interlagos, at real scale and in race direction.

To add another, put its id in `IDS` in `tools/import-circuits.mjs`, run `node tools/import-circuits.mjs`, then add its settings to `SETTINGS` in `src/track.js`, with medal times from `node tools/medal-times.mjs`. Ids are listed in `data/f1-circuits.geojson` (40 circuits). Circuits that cross themselves, like Suzuka, need bridge support first.

## Blog

Posts are Markdown files in `posts/`; `node tools/build-blog.mjs` turns them into `blog/` (one page per post, the
index and an RSS feed), `sitemap.xml`, `robots.txt` and the "From the blog" cards on the home page. Commit what it
writes. How posts are written (voice, layout, rules, the game tie-in) is in `posts/_guide.md`; change that file to
change the style. Every post ends with a button into the game, on the post's circuit when it sets `circuit:`.

Posts go live at their `date:` (India time, like `2026-10-29 09:00`). Until then the build leaves them out, and the
`Publish blog` GitHub Action (`.github/workflows/publish-blog.yml`) rebuilds and commits every 15 minutes from 8:30am
to 7:15pm India time, and whenever posts land on `main`, so a post goes live within about 15 minutes of its time. A Claude routine writes each day's four posts at 3:30am following
`posts/_daily.md`. `node tools/build-blog.mjs --drafts` shows scheduled posts locally; don't commit that build. Post photos come from Wikimedia Commons via `node tools/commons-photo.mjs "File:<title>.jpg" media/blog/<post>.jpg`.

## Circuit pages and search

`content/circuits/<slug>.md` holds each circuit's history and corners; the same build turns them into
`circuits/<slug>.html` (with the track map drawn from the game's geometry, its medal times and related posts) and the
`circuits/` index. The build also writes `sitemap.xml`, `sitemap-news.xml` (the last two days' posts) and robots.txt,
and stops on em or en dashes, or on trademarked names (`TRADEMARKS` in `tools/build-blog.mjs`) anywhere in the game:
its code, its pages and the circuit pages say "the world championship" or "Grand Prix racing", and name circuits by
their town. Blog posts are news and history, so they say F1 and Formula 1. After publishing, the Action tells IndexNow
search engines about new pages with `tools/indexnow.mjs`, using the key file at the site root. `.vercelignore` keeps
sources (`posts/`, `content/`, `tools/`, `supabase/`) off the live site, and `vercel.json` redirects renamed posts.

## Medals and car colours

Each circuit has bronze, silver and gold lap times (`medals` in `SETTINGS`, `src/track.js`): the best laps of a lone easy, medium and hard AI driver, rounded up to the half second. A clean lap (not rescued) that beats one wins that medal. Medals unlock car colours in the Garage (`COLOURS` in `src/medals.js`); a gold counts as three, so all 18 medals is every circuit on gold. Players without the medals can buy a colour instead (₹99 to ₹499), once the shop is set up. Retune the times if the car's handling or the AI changes.

## Controls

Arrows or WASD to drive, T reset to track, R restart, K keep lap (rewarded ad, on portals), L racing line, C camera, G ghost, M sound, Esc pause. In the menu, ↑/↓ pick a circuit and Enter starts.

Gamepad (standard mapping): left stick or d-pad steers, RT or A throttle, LT or B brake, Y resets to track, X keeps the lap, Start pauses, Back restarts.

On touch screens, steering buttons appear on the left and pedals on the right; the ↺ button at the top resets to track.

The racing line is painted green (throttle), yellow (lift) and red (brake). It's off by default; turn it on in Settings or with L, full or braking zones only. Go off track (or hit a wall hard) three times within two minutes and the game pauses to offer the line and a lap restart; it asks at most once per run and stops after being waved off twice. Braking boards at 150, 100 and 50 m count down to every stop that loses more than about 70 km/h. Reset to track puts the car back on the track at the nearest point, stopped; the lap carries on, and the usual off-track rule decides if it counts.

The default chase camera turns with the car, so left is always screen-left. C cycles chase, cockpit (first person, WebGL; falls back to chase where WebGL isn't available) and top-down. Settings also has the cameras, steering sensitivity (low / normal / high), racing line, ghost and sound, and a reset for saved lap records.
